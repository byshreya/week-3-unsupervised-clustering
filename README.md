Week 3: Unsupervised Learning and Clustering Analysis

Project Overview

This project applies the K-Means clustering algorithm to the Mall Customers dataset to identify customer groups based on age, annual income, and spending score.

Objectives

- Explore and preprocess the dataset.
- Apply feature scaling using StandardScaler.
- Select a suitable number of clusters using the Elbow Method and Silhouette Score.
- Perform customer segmentation using K-Means clustering.
- Analyze and interpret the resulting customer groups.

Dataset

Mall Customers dataset: https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

Tools and Libraries

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Methodology

1. Data exploration and preprocessing.
2. Feature selection and standardization.
3. Evaluation of cluster numbers.
4. K-Means clustering with five clusters.
5. Cluster analysis and interpretation.

Results

The final model identified five customer clusters and achieved a Silhouette Score of approximately 0.4166. The clusters showed different patterns in customer age, annual income, and spending score.

Project Files

- "Week_3_Clustering_Analysis.ipynb" — Google Colab notebook.
- "Week_3_Clustering_Report.docx" — Project report.
- "Mall_Customers.csv" — Original dataset.
- "Mall_Customers_Clustered.csv" — Dataset containing the assigned cluster labels.

Conclusion

This project demonstrates how unsupervised machine learning can be used for customer segmentation and exploratory customer behaviour analysis.
